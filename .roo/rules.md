## Before you start — read the context map

**Step 1 — Read `.decispher/overview.md`** (always, on every new session or task).
It contains the always-true rules and the full topic index for this project.

**Step 2 — Read `.decispher/index.json`** for the machine-readable topic map,
MCP endpoint, and available tools.

**Step 3 — Fetch the relevant topic** before writing or reviewing code:
`decispher.get_context_for_topic({ topic: "<topic>" })`

Do NOT write code, suggest changes, or answer architecture questions before completing
steps 1–3. The context map is the source of truth for this project's decisions and
constraints. Skipping it risks violating active rules.
